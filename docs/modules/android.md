## WebView

| Налаштування | Значення | Навіщо |
|---|---|---|
| Адреса сторінки | `https://appassets.androidplatform.net/www/index.html` | Справжній https-домен: працюють воркери перевірки помилок, `fetch`, шрифти. Усі запити до нього перехоплює [`Server`](files.md#server--віртуальні-сайти) і віддає файли з `assets/www` |
| JavaScript, DOM Storage | увімкнено | Ace і інтерфейс |
| `setAllowFileAccess`, `setAllowContentAccess` | вимкнено | Сторінка не читає файли напряму — лише через міст |
| `setTextZoom(100)`, без масштабу | — | Системний розмір шрифту не ламає розмітку; масштаб коду — власний (щипок) |
| `MIXED_CONTENT_COMPATIBILITY_MODE` | — | Сторінки, які запускає користувач, можуть тягнути http-ресурси |
| `windowSoftInputMode=adjustResize` | — | Клавіатура зменшує WebView, рядок клавіш лишається над нею |
| `configChanges` | поворот, розмір, клавіатура, тема, щільність | WebView не перезавантажується — редактор не губить стан |

Посилання на зовнішні сайти в головному фреймі відкриваються в браузері. Якщо процес рендерингу WebView падає (брак пам’яті), Activity перезапускається, а сторінка відновлює сесію.

Колір рядків стану й навігації задає сторінка (`bars`) — під тему інтерфейсу.

## Безпека мосту

Android впроваджує об’єкт `addJavascriptInterface` **в усі фрейми** WebView, включно з iframe. А в iframe працюють сторінки, які запускає користувач, — разом із чужими скриптами з CDN. Тому:

1. Кожен метод мосту першим параметром отримує **маркер**. Його видає метод `hello()` лише один раз за завантаження головної сторінки; скидається він тільки на `onPageStarted` головного фрейму.
2. Сторінки перегляду живуть на **іншому домені** — `preview.appassets.androidplatform.net` — і в iframe з `sandbox` без `allow-top-navigation`. Вони не можуть прочитати маркер у батьківської сторінки й не можуть перезавантажити її.

## JS-міст `window.Android`

Усі методи синхронні й повертають рядки (JSON), окрім тих, де результат приходить подією. На боці сторінки їх обгортає `native.js` (`Native.read(...)` тощо).

| Група | Методи |
|---|---|
| Службові | `hello()`, `info()` — версія, SDK, модель, нічна тема; `encodings()` — список кодувань |
| Файли | `read(uri, enc)` → метадані, текст забирається окремо `text()` (без JSON-екранування великих рядків); `write(uri, text, enc, bom, eol)`; `unmappable(text, enc)`; `stat(uri)` |
| Вибір | `pick(id, kind, name)` — `open` (кілька файлів), `folder`, `save`; результат — подією `__kod.onPick(id, json)` |
| Папка | `list(tree, id)`, `docUri`, `rootId`, `create(tree, parent, name, dir)`, `rename`, `remove`, `resolve(tree, "a/b.txt")`, `treeName` |
| Пошук у папці | `find(id, tree, startId, startPath, opts, replace)` → порції результатів подією `__kod.onFind`; `cancel(id)` |
| Сховище | `kvPut` / `kvGet` — сесія, налаштування, недавні, макроси; `backupPut` / `backupGet` / `backupDel` / `backupKeys` — незбережений текст вкладок |
| Система | `clipGet` / `clipSet`, `share(text, name)`, `view(url, mime)`, `hash(text, algo)`, `print(html, title)`, `bars(color, light)`, `debug(on)`, `exit()` |
| Дозволи на URI | `persisted()`, `release(uri)` — щоб не впертися в ліміт постійних дозволів Android |
| Перегляд | `previewSet({tree, files})` — що віддавати на домені перегляду |
| Інтенти | `intent()` — забрати відкладений інтент (файли або текст) |

### Формат `read()`

```json
{
  "ok": true, "name": "notes.txt", "size": 2048, "mtime": 1761290000000, "writable": 1,
  "enc": "windows-1251", "bom": false, "eol": "CRLF", "mixed": false, "binary": false
}
```

Помилки: `"err": "big"` (понад 32 МБ), `"access"` (немає дозволу) або текст винятку.

## Вибір файлів і папок

| Дія | Інтент | Що робимо з результатом |
|---|---|---|
| Відкрити | `ACTION_OPEN_DOCUMENT`, `*/*`, кілька файлів | `takePersistableUriPermission` на читання й запис (або лише читання) |
| Папка | `ACTION_OPEN_DOCUMENT_TREE` | Постійний дозвіл на дерево; назва — з кореневого документа |
| Зберегти як | `ACTION_CREATE_DOCUMENT` з назвою | Тип файлу — з розширення; для невідомих — `application/octet-stream`, щоб постачальник не дописав `.txt` |

Для `<input type="file">` у запущених сторінках працює `onShowFileChooser`.

## Інтенти від інших застосунків

| Інтент | Типи | Що відкривається |
|---|---|---|
| `VIEW`, `EDIT` | `text/*`, JSON, JavaScript, XML, shell, Python, PHP, SQL, YAML, TOML, `application/octet-stream` | Файл у новій вкладці; якщо інтент дав постійний дозвіл — він зберігається |
| `SEND` | текст | Нова вкладка з цим текстом (тема листа — назва вкладки) |
| `SEND` / `SEND_MULTIPLE` | файли | Кожен файл у своїй вкладці |

Activity у режимі `singleTask`: повторне «Відкрити за допомогою» приходить у `onNewIntent` і не створює другий екземпляр.

## Події для сторінки

| Подія Activity | Виклик на сторінці |
|---|---|
| `onPause` | `__kod.pause()` — записати резервні копії і сесію; автозбереження «при згортанні» |
| `onResume` | `__kod.resume()` — перевірити, чи не змінилися файли ззовні |
| Зміна теми системи | `__kod.config(night)` |
| Кнопка «Назад» | `__kod.back()` → `'handled'` (закрито аркуш, панель, пошук) або `'exit'` |
| Новий інтент | `__kod.onIntent()` |

## Друк і «Поділитися»

- **Друк**: сторінка готує HTML з підсвіченим кодом, Activity завантажує його в окремий невидимий WebView і передає `PrintManager` — звідти друк або «Зберегти як PDF».
- **Поділитися файлом**: текст записується в `cache/share/`, а `FileShareProvider` (власний мінімальний `ContentProvider` замість AndroidX `FileProvider`) видає на нього `content://` з тимчасовим дозволом на читання.
