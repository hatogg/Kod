## Вкладка

Один екземпляр Ace (`K.ed`) на весь застосунок. У кожної вкладки своя `EditSession`: текст, історія «Скасувати», режим мови, згортки, курсори. Перемикання вкладки — це `K.ed.setSession(tab.session)`.

| Поле `Tab` | Значення |
|---|---|
| `uri`, `tree`, `docId`, `path` | Звідки файл: документ або документ у дереві папки (шлях відносно кореня) |
| `enc`, `bom`, `eol`, `mixed` | Кодування, BOM, кінці рядків, чи були вони змішані |
| `mode` | Режим Ace (`javascript`, `python`…) |
| `readOnly`, `binary`, `big` | Тільки читання; двійковий файл; великий (без підсвітки й перевірки) |
| `mtime`, `size` | Для перевірки змін ззовні |
| `bookmarks` | Множина рядків |
| `forceDirty` | «Є що зберігати», навіть якщо текст той самий (змінили кодування чи кінці рядків) |
| `loaded` | Вкладки з відновленої сесії читаються з диска лише під час першої активації |

**Незбережені зміни** — це `!undoManager.isClean() || forceDirty`. Тому якщо скасувати зміни до стану після збереження, крапка на вкладці зникне.

**Мова** визначається з розширення через `ext-modelist`, а для файлів без розширення — з першого рядка (`#!/bin/bash`, `#!/usr/bin/env python`, `<?xml`, `<!doctype html>`, JSON).

**Воркери перевірки помилок** (JS, CSS, HTML, JSON, PHP, XML, Lua, YAML…) завантажуються через `fetch` і запускаються з `blob:`-адреси. Так вони працюють на будь-якій версії WebView, незалежно від того, чи перехоплює вона запити воркерів.

## Відкриття і збереження

```
Files.open(uri)
  ├─ уже відкритий? → перейти на вкладку
  ├─ Native.read: помилка → повідомлення, прибрати з «Недавніх»
  ├─ понад 6 МБ → спитати, відкрити без підсвітки
  ├─ двійковий → «Тільки читання» / «Редагувати» / «Скасувати»
  ├─ нова вкладка; порожня «новий N» поруч замінюється
  └─ «Недавні»; якщо кінці рядків змішані — підказка

Tabs.save(tab)
  ├─ немає uri → «Зберегти як…» (ім’я «новий-1.js» за мовою)
  ├─ однобайтове кодування й символи не вміщаються → «Записати» / «UTF-8» / «Скасувати»
  ├─ Native.write(uri, text, enc, bom, eol)
  │    └─ немає доступу → запропонувати «Зберегти як…»
  └─ markClean: позначка без змін, видалити резервну копію, оновити сесію
```

`Tabs.close` для вкладки зі змінами питає «Зберегти / Не зберігати / Скасувати». Остання закрита вкладка замінюється новою «новий 1», як у Notepad++.

**Автозбереження** (налаштування): «при згортанні» зберігає вкладки зі змінами в `__kod.pause()`, «через 2 с після змін» — тихо після паузи в наборі. Незбережені вкладки без файлу тільки резервуються.

## Сесія і резервні копії

| Що | Коли | Куди |
|---|---|---|
| Текст вкладки зі змінами | 1,2 с після зміни (5 с для файлів понад 20 000 рядків) | `backup/<id вкладки>` |
| Метадані всіх вкладок, активна вкладка, відкрита папка й розгорнуті гілки | 0,7 с після будь-якої зміни стану | `kv/session` |
| Усе одразу | `__kod.pause()`, `visibilitychange`, `pagehide`, вихід | — |

Під час відновлення вкладки створюються «лінивими»: активна читається відразу, інші — коли на них перейдуть. Вкладка зі змінами бере текст із резервної копії й лишається позначеною як незбережена. Копії вкладок, яких уже немає в сесії, видаляються.

## Зміни ззовні

`Tabs.checkExternal()` викликається на `resume`: для кожної завантаженої вкладки з файлом порівнює `mtime` і розмір (розбіжність до 1,5 с при тому самому розмірі — не зміна).

- вкладка без змін і ввімкнено «Оновлювати файли» → тихо перечитати, курсор і прокрутка лишаються;
- інакше → діалог «Лишити мою версію / Перечитати».

Перечитування робить `doc.setValue`, тож його можна скасувати.

## Операції з текстом — `edit.js`

| Група | Функції |
|---|---|
| Рядки | `mapLines` — над виділеними рядками або всім файлом: сортування (`Intl.Collator('uk')`, числове, за довжиною, без регістру), обернути, дублікати (усі або сусідні), порожні рядки, пробіли, табуляції ↔ пробіли з урахуванням ширини табуляції |
| Текст | `mapText` — над кожним виділенням (кілька курсорів) або словом під курсором: регістр («Кожне Слово», «Речення», інвертувати), перетворення з [інструментів](tools.md) |
| Курсори | `blockSelect` — прямокутник із звичайного виділення; `cursorsAtLineEnds`; `insertSequence` — числа з кроком і доповненням нулями (`01, 1` → 01, 02, 03) |
| Кодування | `convertEncoding` (з підрахунком символів, що не вміщаються), `reopenEncoding`, `eolMenu`, `indentMenu` (вручну, визначити, перетворити відступи) |
| Інше | `gotoLine` (`120` або `120:8`), `setLanguage` (усі мови з пошуком), `toggleReadOnly`, `insertDate` (5 форматів), `stats` |

Рядок стану (`Status`) показує позицію, виділення або кількість курсорів, помилки, запис макросу, тільки читання, мову, відступи, кодування й кінці рядків; кожен пункт натискається.

## Закладки

Закладка — це клас `kod-bm` на номері рядка (`session.setBreakpoint`). Ace сам не зсуває такі позначки, коли додаються чи видаляються рядки, тому `Edit.shiftBookmarks` перераховує їх на кожну зміну:

- вставка `n` рядків → закладки нижче зсуваються на `n`; закладка на рядку вставки зсувається, лише якщо вставили на початку непорожнього рядка (рядок «поїхав» униз);
- видалення рядків → закладки нижче піднімаються, закладки з видаленого діапазону зливаються в його перший рядок.

## Пошук і заміна — `search.js`

Панель використовує `Search` з Ace:

- **живий пошук**: під час набору курсор стає на найближчий збіг від позиції, де почали шукати; усі збіги підсвічуються власним маркером `kod-search-hl`;
- **лічильник** «3/17» — `findAll` по сесії і пошук поточного виділення серед знайдених діапазонів;
- **у виділенні** — діапазон з якорями (`doc.createAnchor`), тому він рухається разом із текстом;
- **заміна** в режимі regex перетворює `\n`, `\t`, `\\` на справжні символи, групи `$1` працюють через JS `String.replace`;
- **історія** останніх 20 запитів і замін — у `<datalist>` і `kv/search`.

**«Знайти у файлах»** — окрема сторінка. Для папки проєкту працює [`Finder`](files.md#finder--пошук-і-заміна-в-папці) на Java з потоковими результатами. Для відкритих вкладок пошук іде в JavaScript по документах Ace; заміна у вкладках не зберігається на диск і скасовується в кожній вкладці.

## Папка проєкту — `workspace.js`

`K.ws = { tree, name, rootId, open: Set(розгорнутих id), cache: Map(id → діти) }`.

- **Дерево** малюється рекурсивно з кешу; «Оновити» скидає кеш. Розгорнуті гілки зберігаються в сесії; під час відновлення папка перевіряється пробним `list`, і якщо дозвіл втрачено, вона не відкривається.
- **Створення зі шляхом** `css/main.css` створює відсутні папки по дорозі; новий порожній HTML отримує заготовку сторінки.
- **Перейменування** оновлює відкриті вкладки цього файлу або всіх файлів у перейменованій папці: для них заново визначаються `docId` і `uri`, бо в Android ідентифікатор документа містить шлях.
- **Видалення** не закриває відкриті вкладки — вони стають файлами без місця, з позначкою «є що зберігати».
- **Недавні** — до 40 файлів. Коли файл випадає зі списку і він не відкритий, постійний дозвіл на нього звільняється (`release`).
