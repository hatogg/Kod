## Запуск і консоль

```
Tools.run(tab)
  ├─ previewFiles: текст усіх відкритих вкладок цієї папки (або вкладок без папки) → { шлях: текст }
  ├─ JavaScript → додається сторінка __kod_run__.html зі <script src="файл.js"> (type="module", якщо є import/export)
  ├─ Native.previewSet({ tree, files })
  └─ iframe https://preview.appassets.androidplatform.net/<шлях>
       sandbox: scripts, forms, modals, popups, same-origin (свій домен), downloads
```

- **Сервер перегляду** спершу шукає файл серед вкладок, потім у папці проєкту. Тому сторінка бачить незбережені CSS і скрипти, а картинки й шрифти бере з диска ([`Server`](files.md#server--віртуальні-сайти)).
- **`hook.js`** вставляється в кожну HTML-сторінку. Він перехоплює `console.log/info/warn/error/debug/table/clear`, `window.onerror` і `unhandledrejection` та пересилає їх у редактор через `postMessage`. Значення форматуються в читабельний вигляд: масиви, об’єкти до 4 рівнів, `Map`, `Set`, дати, елементи DOM (`<li#id.class>`), циклічні посилання.
- **Поле `›`** надсилає код у сторінку (`postMessage {__kodEval}`); `hook.js` виконує його непрямим `eval` у глобальному контексті сторінки й повертає результат (для `Promise` — після виконання). Редактор приймає повідомлення лише від свого iframe (`e.source`).
- Консоль має три стани: згорнута з лічильником (червоним, якщо є помилки), відкрита й велика. Для JavaScript вона відкрита одразу, для HTML — сама відкривається при першій помилці.

## Markdown

Власний перетворювач (`MD.render`), без сторонніх бібліотек:

- **блоки**: заголовки `#` і підкреслені, абзаци, цитати (вкладені), списки (вкладені, нумеровані з довільного числа, списки справ `- [x]`), таблиці з вирівнюванням колонок, огороджені й відступлені блоки коду, горизонтальні лінії, HTML-блоки як є;
- **рядкові**: `код`, **жирний**, *курсив*, ~~закреслений~~, посилання, картинки, автопосилання, переноси рядка, екранування `\*`;
- **підсвітка коду** в блоках з мовою (` ```js `) — через `ext-static_highlight` Ace у поточній темі.

Результат показується в iframe без скриптів (`sandbox` лише з popups), відносні картинки підтягуються з папки проєкту через сервер перегляду.

## Порівняння

`Tools.compare(tab)` порівнює з іншою вкладкою, версією на диску (`Native.read`) або буфером обміну. Сам діф рахує `ext-diff` з Ace:

- на вузькому екрані — один редактор, у якому видалені рядки показано над доданими;
- на широкому — два редактори поруч із синхронною прокруткою (перемикається кнопкою);
- підсумок «+2 −1 · 3 зміни», стрілки ведуть до наступної чи попередньої зміни;
- обидва редактори доступні лише для читання, з підсвіткою мови і поточною темою.

## Форматування — `format.js`

Для JavaScript, TypeScript, Java, C/C++, C#, Kotlin, Go, Rust, Swift, Dart і подібних мов — власний форматувальник, що працює з токенами підсвітки Ace, а не з рядками:

| Правило | Приклад |
|---|---|
| Блок `{` — перенос і відступ, `}` на своєму рядку | `if(x){a()}` → три рядки |
| `} else`, `} catch`, `} finally`, `} while` — на одному рядку | |
| Літерал `{ … }` після `=`, `(`, `,`, `:` лишається в рядку, якщо автор так написав | `const o = { a: 1, b: [1, 2] };` |
| `;` поза дужками `for(…)` — кінець рядка | |
| Пробіли біля `=`, `===`, `=>`, `&&`, `+` (у JS ще біля `*`, `<`, `>`…), після `,` і `:`, після `if`/`for`/`while` | `i<3` → `i < 3` |
| Унарні оператори без пробілу | `!ok`, `-1`, `i++` |
| `case …:` — тіло з відступом | |
| Рядок, що починається з `.`, — додатковий відступ | ланцюжки `.then()` |
| Авторські переноси рядків зберігаються, порожніх рядків — не більше одного поспіль | |

Рядки, шаблонні рядки, регулярні вирази й коментарі переписуються як є. Після форматування результат перевіряється: без урахування пробілів текст має збігтися з оригіналом, а рядки, регулярні вирази й коментарі — бути тими самими. Якщо щось не так (наприклад, Ace сприйняв `/[<>]/` як тег JSX), застосовується безпечний `reindent`, який змінює лише відступи на початку рядків.

HTML, CSS, SCSS, LESS, PHP і XML форматує `ext-beautify` з Ace, JSON — `JSON.stringify` з відступом поточної вкладки. Форматування — одна зміна в історії, тому одне «Скасувати» повертає все.

## JSON і перетворення

| Інструмент | Як |
|---|---|
| JSON: перевірити | `JSON.parse`; позиція помилки перетворюється на рядок і колонку, курсор стає туди |
| JSON: красиво / в рядок / сортувати ключі | Для виділеного або всього файлу; ключі сортуються рекурсивно |
| Base64 | Через UTF-8 (`TextEncoder`), розкодування перевіряє, що вийшов правильний UTF-8 |
| URL, HTML-сутності, рядок JS | `encodeURIComponent`, `textarea.innerHTML`, `JSON.stringify` / `JSON.parse` |
| Транслітерація | Офіційна таблиця КМУ 2010: «зг» → zgh, `Є Ї Й Ю Я` на початку слова → Ye Yi Y Yu Ya |
| Хеші | MD5, SHA-1, SHA-256, SHA-512 — `MessageDigest` на Java від тексту в UTF-8 |

## Список функцій, помилки, друк

- **Список функцій** — аркуш з фільтром: значок виду (`ƒ` функція, `m` метод, `C` клас, `T` тип, `#` заголовок), вкладеність за відступом, номер рядка. Пункт, найближчий до курсора, підсвічено. Самі вирази для мов — у [`langs.js`](ui.md#мови--langsjs).
- **Помилки** — анотації воркера поточної вкладки, відсортовані за рядком.
- **Друк** — `ext-static_highlight` малює код у світлій темі з номерами рядків, назва файлу стоїть у заголовку, а міст передає HTML системному друку ([Android-частина](android.md#друк-і-поділитися)).
