### Як рухаються дані

```
Вибір файлу Android (SAF)          Файловий менеджер («Відкрити за допомогою»)
        ↓ content:// URI                      ↓ Intent VIEW / EDIT / SEND
MainActivity ── постійний дозвіл на URI ──→ JS: __kod.onPick / __kod.onIntent
        ↓ Android.read(uri)
Files.readBytes → Encodings.read: кодування, BOM, кінці рядків → текст з "\n"
        ↓
tabs.js: вкладка = сесія Ace (свій текст, історія, режим мови, закладки)
        ↓ кожна зміна                             ↓ «Зберегти»
Store: резервна копія за 1–5 с          Encodings.write → Files.writeBytes ("wt")
```

### Принципи

1. **Файли — через систему.** Жодних дозволів на сховище: документи й папки відкриваються вибором файлів Android, доступ до них зберігається між запусками.
2. **Нічого не губиться.** Незбережений текст потрапляє в резервну копію через секунду після зміни, сесія — з курсорами, згортками й закладками — відновлюється після перезапуску чи збою WebView.
3. **Файл лишається таким, яким був.** Кодування, BOM і кінці рядків визначаються під час читання і повертаються під час запису; якщо символи не вміщаються в кодування, редактор попереджає.
4. **Чужий код — в ізоляції.** Сторінки, які ви запускаєте, працюють на окремому домені в пісочниці й не бачать мосту з файлами.
5. **Телефон — головний пристрій.** Великі цілі дотику, рядок клавіш, панель над виділенням, але й повний набір клавіш Notepad++ для фізичної клавіатури.
